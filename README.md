# 🗓️ Shifter App (Telegram Web App)

**Shifter** — це сучасний веб-застосунок, інтегрований безпосередньо в Telegram (Telegram Web App), створений для керування графіками роботи співробітників, відстеження KPI, створення задач та комунікації всередині команди роздрібних магазинів.

Додаток має сучасний, "iOS-подібний" дизайн з підтримкою світлої та темної тем, плавними анімаціями та інтуїтивно зрозумілою навігацією за допомогою плаваючої нижньої панелі (Bottom Tab Bar).

---

## ✨ Основний функціонал

Функціонал розділений на основі ролей (**Admin** - Глобальний Адмін, **SM** - Менеджер Магазину, **SSE** - Заступник, **SE** - Співробітник, **Guest** - Гість/Новачок), забезпечуючи відповідний рівень доступу та конфіденційності даних для кожної ролі.

### 📅 Керування графіками
* **Інтерактивна сітка (Grid View):** Зручний перегляд змін на місяць з кольоровим кодуванням за часом. Популярні зміни мають жорстко закріплені унікальні кольори для кращої візуальної відмінності.
* **Календар та Список:** Персональний вигляд графіку для кожного співробітника.
* **Кастомні зміни:** Додавання кастомного часу зміни через нативне модальне вікно.
* **Статуси:** Відмітки про відпустки (🌴), лікарняні (💊), та донорство (🩸).
* **Гостьові зміни та Підміни:** Відображення змін співробітників, які працюють як гості в інших магазинах, та підмін. Підміни мають спеціальне маркування (📍).

### 📊 KPI та Дашборд
* **Дашборд:** Стартовий екран з компактною свайп-каруселлю, що відображає підсумок годин, прогрес KPI та **статус сьогоднішньої зміни**.
* **Live Status ("Зараз"):** Відображає, хто саме зараз працює в обраному магазині в реальному часі.
* **Персональна статистика:** Окрема сторінка зі статистикою співробітника (дні без лікарняних, улюблені зміни, загальна кількість годин, тощо).

### 📌 Задачі та Комунікація
* **Задачі (Todo List):** Адміністратори та SM можуть призначати завдання співробітникам (або групам). Трекінг виконання (В процесі, Виконано, Відкладено) з підтримкою дедлайнів.
* **Новини (Announcements):** Публікація важливих повідомлень з підтримкою медіа та файлів.
* **Запити (Requests):** Співробітники можуть надсилати запити на вихідні або зміни в графіку, які менеджери можуть схвалювати або відхиляти безпосередньо з Telegram.
* **Нотатки:** Створення особистих та публічних нотаток.
* **Переведення між магазинами:** SE може запросити переведення в інший магазин за кодом, SM отримує запит і підтверджує його.

### 🏆 Гейміфікація та Досягнення
* **Автоматичні бейджі:** Нагороди за досягнення (🛡️ Сталевий імунітет, 🔥 Трудоголік місяця, 🎖️ Ветеран, 🩸 Донор, 🦉 Охоронець ТРЦ).
* **Кастомні бейджі:** Адміністратори (SM) можуть створювати власні бейджі з будь-якими емоджі та текстом.

### 🎨 Персоналізація та Інтеграції
* **Колірні теми:** Вибір з декількох сучасних колірних палітр з повною підтримкою Темного режиму, який синхронізується з темою Telegram.
* **Експорт в Календар (iCal):** Генерація унікального iCal-посилання (`calendarToken`) для імпорту графіка змін у зовнішні календарі.
* **Експорт PDF:** Адміністратори можуть завантажувати розклад магазину в PDF форматі.
* **Тимчасові співробітники:** Швидке створення тимчасових акаунтів для новачків/стажерів з автогенерацією коду запрошення.

### 🛠 Адміністративна панель
* **Глобальні налаштування:** Створення та видалення магазинів, налаштування нормогодин, тривалості обіду.
* **Звільнення та Видалення:** SM може звільняти співробітників, Admin має права на повне видалення (Soft/Hard delete).
* **Логування (Audit Log):** Відстеження дій користувачів у системі ("Хто, що і коли змінив").

### 🔐 Безпека та Авторизація
* **Хешування паролів:** `bcrypt` для зберігання паролів.
* **Telegram Авторизація (Deep Links):** Прив'язка акаунту через `/start auth_<userId>` для миттєвого входу та отримання сповіщень.
* **Ізоляція даних магазинів:** Співробітники бачать інформацію тільки свого поточного магазину, якщо не є гостями.

### 🤖 Інтеграція з Telegram та Сповіщення
* **Telegram Web App:** Додаток працює прямо в чаті, використовуючи `Menu Button` або inline-клавіатури.
* **Боти-сповіщення (Telegram):** Бот (`bot.js`) надсилає зведення та важливі повідомлення безпосередньо в призначені теми (Topics). Підтримка команд (напр. `/start`).
* **Команди для Telegram-груп (Topics):**
  * `/link_store КОД` — прив'язує групу до конкретного магазину (КОД — це унікальний ідентифікатор магазину, який призначає Адміністратор при його створенні; його можна знайти в налаштуваннях магазинів).
  * `/set_news` — встановлює поточний топік (Topic) для публікації новин.
  * `/set_evening` — встановлює поточний топік для вечірніх звітів.
  * `/set_report_time ГГ:ХХ` — встановлює час для автоматичного запиту вечірнього звіту.
* **Браузерні Push-сповіщення:** Підтримка Web Push-повідомлень (VAPID) з можливістю налаштування преференцій у профілі.
* **In-App Notifications (SSE):** Серверні події (Server-Sent Events) для миттєвих сповіщень всередині додатку (повідомлення про бейджі, задачі тощо).

## 🚀 Технологічний стек

* **Frontend:**
  * HTML5, CSS3, JavaScript (Vanilla JS, ES6 Modules)
  * [Tailwind CSS](https://tailwindcss.com/)
  * Telegram Web Apps API (`telegram-web-app.js`)
* **Backend:**
  * [Node.js](https://nodejs.org/)
  * [Express.js](https://expressjs.com/)
  * База даних: [MongoDB](https://www.mongodb.com/) + [Mongoose](https://mongoosejs.com/)
* **Інше:**
  * `multer` (завантаження файлів)
  * `bcrypt` (безпека паролів)
  * `node-telegram-bot-api` (інтеграція Telegram-бота)
  * `web-push` (Push-сповіщення)

## ⚙️ Встановлення та запуск (Локально)

1. **Клонуйте репозиторій:**
    ```bash
    git clone https://github.com/Stanistryit/shifter-app.git
    cd shifter-app
    ```

2. **Встановіть залежності:**
    ```bash
    npm install
    ```

3. **Налаштуйте змінні середовища:**
    Створіть файл `.env` у кореневій папці та додайте ваші конфігурації:
    ```env
    PORT=3000
    MONGO_URI=your_mongodb_connection_string
    TELEGRAM_TOKEN=your_telegram_bot_token
    VAPID_PUBLIC_KEY=your_vapid_public
    VAPID_PRIVATE_KEY=your_vapid_private
    SESSION_SECRET=your_secret_key
    ```

4. **Запустіть сервер:**
    ```bash
    node backend/server.js
    ```
    Для режиму розробки: `npm run dev` (за умови наявності nodemon).
